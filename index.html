📐 Mathematical Definitions & Metric Formulas Pretty-printed mathematical definitions
TTR = |V| / Ntotal
Type-Token Ratio (Lexical Diversity): Ratio of distinct words (|V|) to total generated tokens (Ntotal). Values close to 1.0 indicate virtually zero repetition with high lexical discovery, whereas lower values indicate tightly repetitive, canonical vocabulary. Lexical Diversity Ref ↗
VN = | ∪i=1..N words(Oi) |
Cumulative Vocabulary Expansion across N Runs: The total number of distinct words sampled across N sequential runs. Predictable modes stay bounded around canonical high-probability tokens, whereas creative modes continuously sample the long tail, resulting in steep vocabulary growth. Jaccard Ref ↗
Det = (Pairsidentical / C(N, 2)) × 100%
Exact-Match Determinism (%): The percentage of repeated runs that produce 100% byte-for-byte identical output. most-predictable guarantees 100% determinism via greedy decoding, making it essential for structured JSON assertions. W3C Spec #203 ↗

💡 Why Semantic Presets over Raw Hyperparameters?

Under the Blink Prompt API specification, language models running on end-user hardware vary significantly across device architectures (e.g. Mobile NPU vs. Desktop GPU vs. CPU fallback). Numerical temperature and top-K values behave inconsistently across different model sizes and quantizations. samplingMode establishes a portable semantic contract ensuring developers achieve predictable output determinism and diversity regardless of the underlying hardware.
