🎯 Purpose of Multi-Run Repeatability Testing:

Runs the exact same prompt multiple times through LanguageModel.create({ samplingMode }) to observe entropy behavior. most-predictable (Greedy Decoding) guarantees 100% identical outputs across runs (essential for unit tests, code generation, and deterministic workflows). In contrast, creative & most-creative sample different vocabulary paths on every run.

📐 Metrics Glossary & Mathematical Formulations
This studio evaluates empirical repeatability and linguistic properties across on-device Prompt API sampling modes using quantitative formulations from computational linguistics and machine learning.
🎯 Exact-Match Determinism (%) Multi-Run Determinism Tab
Determinism = Nidentical Ntotal × 100%

Definition: The percentage of sequential repeat runs that produce byte-for-byte identical text given the exact same prompt and system instructions.

What it represents: Quantifies output repeatability. most-predictable guarantees 100% determinism via greedy argmax pathing (wt = arg max P(w|w<t)). Under stochastic presets (e.g. creative), determinism drops toward 0% as sampling explores divergent paths.

📈 Lexical Diversity (Type-Token Ratio / TTR %) Linguistic Metric
TTR = |V| N × 100%

Definition: The ratio of unique lexical types (|V|) to total generated words (N), expressed as a percentage.

What it represents: Evaluates vocabulary richness and repetition resistance. A lower TTR reflects repetitive token choices characteristic of deterministic greedy decoding in predictable modes. A higher TTR indicates expressive word choice where the model actively samples from a broader lexicon.

References: Templin, M. C. (1957). Certain Language Skills in Children; Tweedie, F. J., & Baayen, R. H. (1998). How Variable May a Calculation Be? Robustness of Lexical Statistics.
📖 Unique Vocabulary Size (|V|) Set Cardinality
|V| = | {w ∈ Output : w is unique} |

Definition: The cardinality of distinct word types produced in an individual response or accumulated across multiple runs for a preset.

What it represents: Measures the breadth of the explored vocabulary space. Highly predictable modes stay confined to high-frequency core tokens, while creative modes penetrate deeper into the tail of the model's token distribution.

References: Zipf, G. K. (1949). Human Behavior and the Principle of Least Effort; Holtzman et al. (2019). The Curious Case of Neural Text Degeneration.
🔤 Total Word Count (N)
N = ∑ tokens

Total token/word volume generated. Serves as the normalizing denominator for calculating Type-Token Ratio (TTR).

🔀 Unique Variations
Vdistinct = |{clusters}|

Number of distinct response clusters produced across repeatability runs. 1 variation = pure determinism; N variations = full divergence.
